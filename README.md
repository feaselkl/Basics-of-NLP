# The Basics of Speech and Natural Language Processing

This repository provides the supporting code for my presentation entitled [The Basics of Speech and Natural Language Processing](https://csmore.info/on/basicsofnlp).

## Running the Code

In order to run the packages, I recommend [creating a virtual environment](https://youtu.be/Th9Noj_078A). For example:

`python -m venv basicsofnlp`

Then activate your virtual environment.

On Windows: `basicsofnlp\Scripts\activate.bat` or `basicsofnlp\Scripts\Activate.ps1`

On Linux or MacOS: `basicsofnlp/bin/activate`

## Requirements

This project does require Python 3.12 or earlier. The spaCy library does not support Python version 3.13 just yet.
